# Celebration Videos

Place your celebration `.mov` or `.mp4` clip files here, named:

```
celebration1.mp4
celebration2.mp4
celebration3.mp4
celebration4.mp4
celebration5.mp4
```

The app picks one **randomly** every time a 1,000-point milestone is reached.

> The files currently in this folder are tiny placeholder stubs.
> Replace them with real Nick & Judy / Zootopia `.mov` clips (renamed to `.mp4`
> or update the `CELEBRATION_VIDEOS` list in `src/main.ts` to match your filenames).
